# 先反问，再动手

[English](ask-before-coding.md) · [简体中文](ask-before-coding.zh.md) · [全部提示词](README.zh.md)

**什么时候用：** AI 开始做任何东西之前，每一次。

你说得含糊，AI 不会停下来问，它会挑一个说得通的理解一路做下去。让它先复述、先反问，这一步不产出文档，产出的是共识：复述对了、问到点子上了，说明它真听懂了。

```
[把你的一句话规格或开发简报粘在这里。]

动手之前：
1. 用你自己的话复述一遍我要什么，五行以内。
2. 问我 3–5 个最关键的问题，也就是猜错了会浪费最多工作量的那几个。编号。
3. 等我回答。我回答之前不要写代码。

开始做的时候：用高保真的方式做（真实内容；加载/空/出错/成功四种状态都要有；真实交互），
小步进行，每一步做完跑给我看。
```

不知道该问什么，加一行，借一个提问结构：

```
用 [JTBD / 机会解决树 / 从上线公告倒推] 的结构来组织你的问题。
```

复述错了，先纠正复述，再回答问题。这次纠正是整个项目里成本最低的一次修改。
