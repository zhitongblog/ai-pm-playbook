# Prompts

[English](README.md) · [简体中文](README.zh.md)

Copy-paste prompts for each phase of the [method](../method/README.md). Each file says when to use it and gives the prompt in a code block. Replace the parts in `[brackets]`.

| Prompt | Phase | When to use |
|---|---|---|
| [One sentence to a spec](one-sentence-to-spec.md) | Define | You have an idea in one sentence and need a brief the AI can build from |
| [Ask before coding](ask-before-coding.md) | Define | Right before the AI builds anything, every time |
| [Set the project's taste once](project-taste.md) | Design | Start of a project, or the second time you correct the same preference |
| [Break it into small steps](small-steps.md) | Develop | The spec is agreed and building is about to start |
| [Stuck? Reproduce first](stuck-reproduce-first.md) | Develop | The AI keeps failing with a different reason each time |
| [Self-test with four states](self-test-four-states.md) | Validate | The AI says it's done, before you believe it |
| [App Store metadata review](app-store-review.md) | Validate | Before submitting to App Review, or after a rejection |
| [Write a launch post](launch-post.md) | After launch | The product is live and you want to tell people |

They work with any AI coding tool. Have one that worked on a real project? [Submit it](https://github.com/zhitongblog/ai-pm-playbook/issues/new?template=prompt.yml).
