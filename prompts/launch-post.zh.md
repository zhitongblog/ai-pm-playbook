# 写上线帖

[English](launch-post.md) · [简体中文](launch-post.zh.md) · [全部提示词](README.zh.md)

**什么时候用：** 产品上线了，想告诉别人。发论坛、博客、Show HN、Product Hunt、公众号都适用。

放任 AI 自己写，上线帖会塞满形容词、编出来的用户反馈和「颠覆」。这段提示词把它限制在你能拿出证据的东西上：一句话说清是什么、不是什么，仓库里查得到的真实数字，老实交代谁做的、建在什么上面。

```
给 [产品名] 写一篇上线帖，发在 [哪里，那里的读者是谁]。
只用下面这些事实，以及你能在这个仓库里读到的内容。不要编用户、引语、数字、效果。

事实：
- 一句话说它是什么：[比如「免费无广告的 PDF 阅读器，高亮即笔记」]
- 给谁用、解决什么问题：[……]
- 明确不做什么：[……]
- 谁做的、建在什么上面：[比如「两个人做的，建在 WezTerm 的引擎上」；写出上游项目和合作者]
- 怎么做出来的：[比如「用 Claude Code 做的，我负责描述，代码是 AI 写的」]
- 能拿出来的真实数字：[提交数、天数、版本数、平台]
- 遇到过的一个问题，以及怎么解决的：[……]
- 链接：[官网、仓库、商店页]

规则：
- 第一句就说它是什么、给谁用，不铺垫。
- 说人话。不用「颠覆」「革命性」「丝滑」。
- 每个数字都要来自上面的事实或仓库，告诉我每个数字的出处。
- 写清楚它不做什么、还有哪里粗糙。
- 结尾放链接，再提一个你最想听反馈的具体问题。
- 控制在 [N] 字以内。给我两个标题备选。
```

发完之后，用没登录的浏览器或者别的账号打开这篇帖子，确认别人真的看得见。只有你自己看得见的帖子，在你自己的账号里看起来跟正常发布一模一样。
