# 提示词

[English](README.md) · [简体中文](README.zh.md)

对应[方法](../method/README.zh.md)各个阶段、能直接复制的提示词。每个文件写了什么时候用，提示词放在代码块里，把 `[方括号]` 里的内容换成你的。

| 提示词 | 阶段 | 什么时候用 |
|---|---|---|
| [一句话变规格](one-sentence-to-spec.zh.md) | 定义 | 只有一句话的想法，需要一份 AI 能照着做的简报 |
| [先反问，再动手](ask-before-coding.zh.md) | 定义 | AI 动手之前，每一次 |
| [项目口味说一次](project-taste.zh.md) | 设计 | 项目开头，或者第二次纠正同一个偏好的时候 |
| [拆成小步](small-steps.zh.md) | 开发 | 规格对齐了，马上要开始做 |
| [卡住了：先复现，再修](stuck-reproduce-first.zh.md) | 开发 | AI 反复失败，每次理由都不一样 |
| [用真内容和四种状态自测](self-test-four-states.zh.md) | 验证 | AI 说做完了，你相信之前 |
| [上架前审元数据](app-store-review.zh.md) | 验证 | 提交 App 审核之前，或者被拒之后 |
| [写上线帖](launch-post.zh.md) | 上线后 | 产品上线了，想告诉别人 |

任何 AI 编程工具都能用。你有在真项目里管用的提示词？[投稿给我们](https://github.com/zhitongblog/ai-pm-playbook/issues/new?template=prompt.yml)。
