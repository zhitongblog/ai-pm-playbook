# 卡住了：先复现，再修

[English](stuck-reproduce-first.md) · [简体中文](stuck-reproduce-first.zh.md) · [全部提示词](README.zh.md)

**什么时候用：** AI 反复改、改不对，每次给的理由都不一样。

每一次失败的尝试都会留在上下文里，越攒越乱。跳过复现直接修，修好的往往是别的东西：看着好了，过两天它换个样子又回来。

```
停一下，先别再改代码。

1. 给我一个能稳定复现这个问题的最小例子，以及触发它的具体步骤。跑一遍，给我看它失败了。
2. 然后告诉我原因，带证据：哪一行日志、哪个值、哪个文件第几行。「可能是因为……」不算回答。
   不确定的话，告诉我你下一步要查什么来确认。
3. 原因我同意了，你再动手改。
4. 改完用同一个复现例子再跑一遍，给我看它过了。
```

**对话已经拖得很长，** 换个干净的开头：

```
把我们目前对这个问题确定下来的东西总结成一份短笔记：试过什么、排除了什么、证据说明了什么。
我会带着这份笔记开一个新对话。
```

**怪 AI 之前，先手动做一遍同样的操作。** 手动成、自动化不成（比如填得进去但点击没反应），问题在工具或环境，改提示词没用。
