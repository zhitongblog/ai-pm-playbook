# 拆成小步

[English](small-steps.md) · [简体中文](small-steps.zh.md) · [全部提示词](README.zh.md)

**什么时候用：** 规格对齐了，AI 要开始做的时候。也适用于它闷头干了一阵、你已经搞不清改了哪些东西的时候。

判断一步拆得好不好：做完能不能立刻跑起来，看出对不对？不能，就是拆大了。

```
把这个需求拆成几个小步，每一步做完我都能跑起来看到效果（在浏览器里，或者装到我手机上）。

列步骤的规矩：
- 每一步产出一个我能核对的结果，不是一个「模块」。
- 跨平台边界的改动（比如相机采集、文件元数据、导出）单独成一步。
- 给步骤编号，每一步写清楚做完之后我应该看到什么。

然后只做第 1 步。做完启动起来让我看，然后停下。
不在当前这一步里的事不要做。发现别的地方也该改，加进列表留到后面，不要顺手改。
```

之后每一步：「第 N 步看过了，没问题。按同样的规矩做第 N+1 步。」它说「顺便我也把 X 改了」，就让它把 X 退回去，加进列表。
