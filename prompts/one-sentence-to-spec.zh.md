# 一句话变规格

[English](one-sentence-to-spec.md) · [简体中文](one-sentence-to-spec.zh.md) · [全部提示词](README.zh.md)

**什么时候用：** 手里只有一句话的想法，想让 AI 把它整理成能照着做的规格，又不想让它替你编那些还没决定的部分。

直接说「写个规格」，AI 会用猜测把每个空白补上，读起来还很完整。这段提示词让它把要猜的地方标出来，改成问你。

```
我的想法用一句话说是：[你的一句话]。

把它整理成一份简短的开发简报，分七节：
1. 要解决谁的、什么问题？
2. 他们现在怎么凑合？为什么不够好？
3. 做成什么样算成功？写成能核对的东西（数字或数得出来的事实），不要写形容词。
4. 最小可用版本：列出核心动作，一行一个。
5. 关键状态：加载中、空、出错、成功分别是什么样。
6. 约束：平台、风格，以及明确不做什么。
7. 哪些不可逆操作（发布、付款、删除、覆盖）必须等我来按。

规则：
- 不要编答案。我这句话里没说的，写「待确认：」加上问题，不要自己补。
- 简报写完后，把待确认的问题按重要程度排列，最多五个。
- 先不要写任何代码。
```

回答完待确认的问题，让它更新简报，再用[先反问再动手](ask-before-coding.zh.md)开工。做版本或重构，让它按[规格模板](../templates/spec-template.zh.md)来填。
