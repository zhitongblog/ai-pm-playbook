# 社区案例

[English](README.md) · [简体中文](README.zh.md)

用 AI 做出东西的人投来的案例。原型也算；没做成的也算，只要能说清楚为什么。

## 怎么投稿

**简单的办法：** [提一个案例 issue](https://github.com/zhitongblog/ai-pm-playbook/issues/new?template=case.yml)。表单会问你做了什么、链接、用了哪些 AI 工具、花了多久、卡在哪、想对别人说什么。维护者整理成这里的一个文件，署你的名，并把你加进 [CONTRIBUTORS.md](../../CONTRIBUTORS.md)。

**直接提 PR：** 一个案例一个文件夹：

```
cases/community/<你的项目名>/README.md
```

复制 [`_template.zh.md`](_template.zh.md)（或英文版 [`_template.md`](_template.md)）开始写。用哪种语言写都行，我们会补另一种语言的摘要。

微信群里的案例，只有本人同意才会整理进来，并且一定署名。

每个月我们从投稿里选一个作为「本月案例」，完整写成一篇，发在站点和公众号上。

## 好案例长什么样

- **有真东西可以链过去**：网站、商店页面、仓库，至少有截图或一段短视频
- **数字拿得出依据**：天数、提交数、build 数、版本数、用户数。不知道的数字就不写，别估
- **卡在哪写具体。** 「App Store 按条款 2.1(a) 拒了，因为沙盒少一个 entitlement」能帮到下一个人，「上架很难」帮不到
- **一两个决定和理由**：砍掉了什么、坚持了什么、给 AI 立了什么规矩
- **AI 看不见的地方**，以及你是怎么发现的：真机、打包产物、真实用户
- **老实署名**：别人参与过、建在别的项目上，都写出来

不要宣传文案，不要编出来的好评。短而具体，好过长而空。
