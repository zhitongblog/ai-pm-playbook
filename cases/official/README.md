# Official cases

[English](README.md) · [简体中文](README.zh.md)

Four products built with the doaipm method, all with public repos. The code for all four was written almost entirely by AI. Each summary covers what the product is, its timeline, the key decisions, and what went wrong. Numbers are as stated in the doaipm playbook, as of August 2026.

| Case | Form | Size | What it shows |
|---|---|---|---|
| [SoloPDF](solopdf.md) | iOS + macOS, App Store | 43 commits, 6 days | Speed, and where the time really goes when shipping to a store |
| [FreeID Photo](freeid-photo.md) | iOS, App Store | 21 commits, 14 numbered builds | The shortest path from zero to the App Store |
| [SoloMD](solomd.md) | Desktop, website + GitHub | ~669 commits, 84 releases, 551 stars | What happens after launch |
| [Unterm](unterm.md) | Cross-platform terminal | ~521 commits on main, 73 releases | Two people plus AI, built on WezTerm's engine |

The full commit-by-commit traces are in the [playbook](https://doaipm.com/en/presale/). Want your project here? See [community cases](../community/README.md).
