# 官方案例

[English](README.md) · [简体中文](README.zh.md)

四个用 doaipm 方法做出来的产品，仓库全部公开，代码基本都是 AI 写的。每篇摘要讲清楚它是什么、时间线、几个关键决定、出过什么问题。数字以 doaipm 手册所载为准，截至 2026 年 8 月。

| 案例 | 形态 | 体量 | 看点 |
|---|---|---|---|
| [SoloPDF](solopdf.zh.md) | iOS + macOS，App Store | 43 个提交，6 天 | 速度，以及上架时时间实际花在了哪 |
| [FreeID Photo](freeid-photo.zh.md) | iOS，App Store | 21 个提交，其中 14 个编号 build | 从零到上架的最短路径 |
| [SoloMD](solomd.zh.md) | 桌面端，官网 + GitHub | 约 669 个提交，84 个版本，551 star | 上线之后会发生什么 |
| [Unterm](unterm.zh.md) | 跨平台终端 | 主干约 521 个提交，73 个版本 | 两个人加 AI，建在 WezTerm 引擎上 |

按提交逐条的完整追溯在[手册](https://doaipm.com/zh/presale/)里。想让你的项目也出现在这里，看[社区案例](../community/README.zh.md)。
