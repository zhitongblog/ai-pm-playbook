## 5. 自测策略（每项功能强制）

每个功能**声明完成前必须**：
1. **数据往返**：造 fixture → 驱动功能 → 读回断言，确认只改了该改的。
2. **UI 路径**：驱动真实 UI + 截图核验，不是只跑单测。
3. **单元测试**：<涉及哪层就跑哪层>
4. **Git 安全**：前后比对，确认单次编辑 = 干净的最小 diff。
5. **CLI + MCP 冒烟**：新增能力同步暴露到 CLI 和 MCP。
6. **多语言**：新字符串进主语言文件，其余语言占位补齐。

> **红线：自测未过不得声明完成。**
> 有些东西（比如合成键盘事件驱动不动的第三方组件）自动化测不了，
> 那就退到 store 级断言 + 截图核验，**写明降级方案**，不许跳过。
