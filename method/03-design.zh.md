# 阶段 3 · 设计

[English](03-design.md) · [简体中文](03-design.zh.md) · [回到方法总览](README.zh.md)

**目标：** 动手前先看到它大概长什么样，选定一个方向。

## 怎么做

**要几个粗糙方案并排放，看到了再挑。**

```
给 [登录页 / 看板 / 主界面] 做 3 个风格方案：
A 极简，B 商务，C 活泼。
放在同一个页面里，方便我并排对比。
文案用我们产品的真实文案，不要占位文字。
```

（装了技能框架的话，这里用多方案设计技能，站点的环境搭建指南里用的是 `/design-shotgun`。）

**项目口味说一次，以后不用每次重复。** 技术选型、风格、约束、红线，让 AI 存成项目里的长期约定，之后自动遵守：

```
这个项目，请你一直遵守：
· 技术口味：【比如 用 Astro、不引入重框架、能静态就静态】
· 风格：【比如 深色、克制、留白多，文案说人话】
· 约束：【比如 不加任何付费/第三方追踪；移动端优先】
· 红线：【比如 不碰生产数据；删除/发布/付款这类操作先问我】
```

完整提示词见 [`prompts/project-taste.zh.md`](../prompts/project-taste.zh.md)。口味定下来，之后每次产出的风格一致，不用反复纠偏。

**参考别人的设计时，把「不抄什么」写下来。** 只写「学它的克制高级感」，不写「保留我们的暖色」，AI 大概率把配色也一起学过来。

## 做到什么算完

- 选定了一个方向
- 关键页面长什么样，心里有数
- 口味和红线写在了 AI 会读到的地方

## 新手卡点

**一上来就要完美**，反复纠结。先要三个粗糙方案，看到了再挑。打磨放到开发阶段，一小步一小步来。

## 案例里的样子

SoloMD 4.6 的计划里，设计决策连同「不做什么」一起写下：学参考产品的克制高级感，中性灰底加暖橙强调色 `#ff9f40`，8px 圆角，明确写了「不抄它的冷灰蓝」。随后把口味落成具体的值（间距、圆角、z 层的比例尺），这样七个并行的 AI 任务不会各自发明七套间距。见 [SoloMD 案例](../cases/official/solomd.zh.md)和[规格模板](../templates/spec-template.zh.md)第 2 节。
