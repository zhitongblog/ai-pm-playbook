# doaipm 方法

[English](README.md) · [简体中文](README.zh.md)

AI 时代的产品经理，靠把想法说清楚、让 AI 编程工具去做，把一个想法变成能跑的产品。下面是这件事落到手上的做法。更长的版本在 [doaipm.com/zh/method/](https://doaipm.com/zh/method/)。

## 四个前提

### 1. 相信 AI，不找工具

产品经理的老习惯是遇到问题先找工具：画原型找 Figma，做流程找 Axure，要图表找插件，要动效再找一个。大半精力花在挑工具、学工具、拼工具上，真正的问题没动。

新的做法是遇到任何问题，第一反应不是「用什么工具」，是「我怎么跟 AI 说」。调研、写文档、做原型、测试，一个对话里都能出来。

站点上的版本对环境有明确主张：用 Claude，用 Claude Code（能直接跑代码的那个形态，不是网页聊天），订阅够用的档位（建议 Claude Max $100 档起步），每天做高保真才不会被限流打断。方法本身不绑定工具，[Agent Skill](../skills/README.zh.md) 也支持 Codex CLI、Gemini CLI 和 Cursor。

### 2. 不懂代码反而是优势

不懂代码，就不会被「这有多难实现」绑住，只管把想要的说清楚。把话说清楚，正是产品经理的看家本事。

把 AI 当成一个很能干、但需要你交代清楚的实习生。日常用得最多的就三句：

- 「帮我做……」：交代任务
- 「这里不对，应该是……」：给反馈
- 「做之前先问我几个问题」：让它帮你想清楚

在自己的项目目录里怎么折腾都没事。最坏的结果是它做得不好，你说一句「不对，重来」。

### 3. 高保真优先

以前做一个高保真原型要写 PRD、排期、等研发，一两周起步，所以产品经理只能先画草图。现在交给 AI，当天就能跑起来。一件事的成本从奢侈品变成日用品，做事的方式就该跟着变。

保真度分三层：

| 层次 | 形态 | 问题 |
|---|---|---|
| L1 | 描述（文字或口头） | 歧义最大，每个人脑补出不同的东西 |
| L2 | 低保真（线框图、草图） | 看得见框，看不见真实体验 |
| L3 | 高保真（可运行原型） | 能点、能交互、能给真人用 |

直接做 L3。「高保真」落到具体是五件事：

1. 跳过线框图，描述清楚后直接让 AI 生成可运行的原型
2. 真实文案、真实数据结构。假数据可以，Lorem ipsum 和「标题占位」不行
3. 覆盖真实状态：加载中、空数据、出错、成功，不只做顺利的那条路
4. 真实交互：能点、能输入、有反馈
5. 在真设备或真浏览器里看，不在脑子里看

原型代码不是生产代码，也不需要是。它是能交给研发的最精确的需求说明。

### 4. 五个阶段

**发现 → 定义 → 设计 → 开发 → 验证。** 每个阶段有目标、有对 AI 的说法、有完成标准。

| 阶段 | 目标 | 做到什么算完 |
|---|---|---|
| [1. 发现](01-discover.zh.md) | 搞清楚用户要什么、竞品在做什么 | 能用三句话说清用户最痛的是什么 |
| [2. 定义](02-define.zh.md) | 把模糊的想法变成谁都能照着做的需求 | 成功标准和边界情况写下来了，没参与的人也看得懂 |
| [3. 设计](03-design.zh.md) | 动手前先看到大概长什么样，选定方向 | 选定了一个方向 |
| [4. 开发](04-develop.zh.md) | 一小步一小步做出能跑的原型 | 主流程在浏览器或真机上跑通，不报错 |
| [5. 验证](05-validate.zh.md) | 给真人用，用证据做决定 | 真实用户试过，能拿证据回答值不值得继续 |

时间大多花在开发阶段，偷工减料大多发生在验证阶段。

## 安全网

五条底线。有这五条兜着，底线之上才能放开试。

1. **不喂真实敏感数据。** 原型用假数据或脱敏数据
2. **密钥不写进代码。** 用测试专用的凭证
3. **不可逆的事人来按。** 发布、删除、付款，AI 先问，你来按最后那个键
4. **不碰线上系统。** 原型只在本地或测试环境跑
5. **拿不准就问。** 合规、付费、隐私、技术选型，先问能负责的人，再让 AI 动手

越往真实用户那边走，这张网收得越紧。原型可以大胆，生产必须谨慎。

## 反复出现的那一句

**成功要从外部世界读回来，不能由自己判定。**

AI 极少告诉你「我失败了」，它更常告诉你「我完成了」。开发时好好的、打包后全废；脚本报发布成功、平台上什么都没有；设置静默回退成默认值。这些都不报错。核对的办法只有一个：去真设备、真平台上看真结果，看到了再说完成。[上线自查清单](../templates/launch-checklist.zh.md)把这件事拆成了逐条可查的项目。
